# Contributing

Thanks for helping. mexxi changes how coding agents work on real repositories, so every change goes through the same checks and review as the work it governs.

- **Run `npm run verify` before you open a pull request.** It is the repository's one definition of healthy. A failing check means the change is not finished; fix the cause rather than loosening the check.
- **Read [`docs/decisions/`](docs/decisions/) first** when your change touches how mexxi works. Follow the records, or add a new one that supersedes a record you disagree with.
- **Send changes as pull requests.** Work on a branch and open a pull request against `main`.
- **Never push to `main`.** Branch protection and the guard hook back this up, but the rule comes first.

By contributing, you agree that your work is released under the [MIT licence](LICENSE).
